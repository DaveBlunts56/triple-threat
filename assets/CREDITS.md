# Credits

What the player models are made from, and under which licence.

## Generator

- **MPFB 2.0.18** (MakeHuman Plugin For Blender), GPL-3.0-or-later. Used as a tool; its code is not shipped.
  <https://extensions.blender.org/add-ons/mpfb/>

The data MPFB ships with is CC0, as MakeHuman states for its core assets: <https://static.makehumancommunity.org/about/license.html>. The rig's CC0 status rests on its weights file, which states CC0, and on that statement. From it:

| Asset | Used for |
|---|---|
| Base mesh | Every body |
| Body targets, and the face targets under `head`, `nose`, `chin`, `cheek`, `mouth`, `eyes` and `forehead` | Each body's build, and every face but player 0-4's |
| Mixamo rig and weights (`rig.mixamo`) | The skeleton |

## Motion

From **Mixamo** (Adobe), made for this game's own skeleton and baked into `assets/motion.glb` by `tools/blender/build_motion.py`.
Mixamo allows its motion to be used in a game but not passed on as raw clips, so the downloaded `.fbx` files are not in the repository.

| Motion in the game | Mixamo clip | Its description on Mixamo |
|---|---|---|
| `idle` | Breathing Idle | Breathing Idle |
| `walk` | Standard Walk | Standard Walk |
| `run` | Standard Run | Standard Running |
| `sprint` | Sprint | Standard Sprint |
| `jump` | Jumping | Jump Up |
| `strafeLeft` | Goalkeeper Sidestep | Goalkeeper Left Sidestep |
| `backpedal` | Walking Backwards | Walking Backwards |
| `dribble` | Dribble | Dribbling Basketball With Right Arm |

Three motions are not clips of their own: `land` is the frames of `jump`'s clip that follow the landing, and `strafeRight` and `dribbleLeft` are `strafeLeft` and `dribble` in a mirror.
