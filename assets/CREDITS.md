# Credits

What the player models are made from, and under which licence.

## Generator

- **MPFB 2.0.18** (MakeHuman Plugin For Blender), GPL-3.0-or-later. Used as a tool; its code is not shipped.
  <https://extensions.blender.org/add-ons/mpfb/>

## Assets (all CC0)

From the **MakeHuman system assets** pack, CC0:
<https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip>

| Asset | Used for |
|---|---|
| Base mesh and body targets | Every body |
| Mixamo rig and weights (`rig.mixamo`, shipped with MPFB) | The skeleton |
| `skins/young_african_male` | Skin of player 0-4 |
| `eyes/low-poly` | Eyes |
| `eyebrows/eyebrow001` | Eyebrows |
| `eyelashes/eyelashes01` | Eyelashes |
| `hair/short02` | Hair of player 0-4 |
| `clothes/shoes05` | Trainers and socks |

The jersey and shorts are generated by `tools/blender/build_players.py` from the base mesh's own helper surface.

## Motion

From **Mixamo** (Adobe), made for this game's own skeleton and baked into `assets/motion.glb` by `tools/blender/build_motion.py`.
Mixamo allows its motion to be used in a game but not passed on as raw clips, so the downloaded `.fbx` files are not in the repository.

| Motion in the game | Mixamo clip | Its description on Mixamo |
|---|---|---|
| `idle` | Breathing Idle | Breathing Idle |
| `walk` | Standard Walk | Standard Walk |
| `run` | Standard Run | Standard Running |
| `sprint` | Sprint | Standard Sprint |
| `jump` | Jumping | Jump Up |
